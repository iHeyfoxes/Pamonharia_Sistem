# 🌽 Pamonharia

Primeira versão do sistema de pedidos para uma pamonharia.

## Estrutura

- `frontend/` — primeira versão do site do cliente.
- `backend/` — reservado para a API/backend.
- `frontend/index.html` — página inicial.
- `frontend/style.css` — estilos.
- `frontend/script.js` — produtos e carrinho.

## Como testar

Abra `frontend/index.html` no navegador.

A próxima etapa será transformar o protótipo em um sistema completo com backend, banco de dados, painel administrativo e pedidos.
